# 🛡️ 내 보험 한눈에 (1단계 시제품)

여기저기 가입한 보험을 한 곳에 모아 보고, 질병코드를 넣으면 **어떤 보험에서 얼마를 받을 수 있는지** 알려주는 웹앱이에요.

## 실행 방법
`index.html` 파일을 크롬으로 열면 끝! (설치 필요 없음)

## 기능
| 탭 | 하는 일 |
|---|---|
| 📋 내 보험 | 👨‍👩‍👧 가족별 카드(보험 개수·월 보험료) + 가족 전체 합계. 보험마다 납입일·고객센터 번호(누르면 전화) |
| 💰 청구 확인 | 질병코드 + 진단/수술/입원/병원비 → 예상 보험금, 가능/확인필요/불가, 필요 서류 |
| 🔁 중복 체크 | 여러 보험에 겹친 보장 찾기 (실손 중복은 경고) |
| 📂 보험 등록 | ① **증권**(금액·날짜) + **약관**(질병코드·면책·감액 규칙) 올리기 → **제미나이**가 둘을 합쳐 읽기 → ② 확인 후 저장. 원본 파일은 기기에 보관, 근거(약관 몇 조) 표시 |
| ⚙️ 설정 | 제미나이 API 키, 🔒 숫자 4자리 잠금, 백업/불러오기(가족끼리 파일로 나누면 합쳐짐) |

## 계산 규칙 (engine.js)
- 보험 기간(가입일~만기일) 확인
- 면책기간 (예: 암 90일), 감액기간 (예: 1년 50%)
- 소액암 (갑상선암 C73 등) 비율 지급
- 입원일당: 공제일 빼고 × 하루 금액
- 실손 여러 개: 실제 낸 돈까지만 나눠서 (비례보상)

## 파일
- `kcd.js` 질병코드 사전·범위 비교
- `engine.js` 청구 계산·중복 찾기 (화면과 분리 → 나중에 모바일 앱에 그대로 사용)
- `gemini.js` 제미나이로 증권 읽기
- `app.js` / `index.html` / `styles.css` 화면

※ 금액은 예상치예요. 실제 지급은 보험사 심사와 약관에 따라 달라요.
