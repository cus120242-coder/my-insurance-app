보장 내용

📖 이렇게 써요 (3단계)

  1. 👨‍👩‍👧 가족 추가
    📋 내 보험 → ＋ 가족 추가 → 이름 쓰기 (예: 엄마, 큰딸)
    같은 이름은 못 써요. 딸이 둘이면 "큰딸·작은딸"처럼
  2. 📂 보험 등록
    📂 보험 등록 → 누구 보험인지 쓰고 → 증권·약관을 올려 🤖 AI로 읽거나 직접 입력 → 💾 저장
    목록에 있는 보험이면 "📚 이 약관으로 채우기"로 더 쉽게
  3. 💰 청구 확인
    💰 청구 확인 → 누가 아팠는지 고르고 → 진단서의 질병코드(예: C50, J18) → 입원·수술·병원비 넣기 → 🔍 확인

🔑 AI(제미나이) 키 받는 법

증권·약관을 AI가 자동으로 읽게 하려면 필요해요. 없어도 직접 입력하면 돼요.

  1. 인터넷 창에서 aistudio.google.com → 구글 계정으로 로그인
  2. Get API key(API 키 가져오기) → Create API key(API 키 만들기)
  3. AIza로 시작하는 키를 복사 → ⚙️ 설정 → API 키 칸에 붙여넣고 저장

⚠️ 키는 비밀번호와 같아요. 남에게 보내거나 캡처하지 마세요. "결제 설정"은 누르지 않으면 돈이 나가지 않아요.

🔒 내 정보는 어디에?

  • 보험·가족·파일은 이 기기 안에만 저장돼요. 다른 사람이 같은 링크를 열어도 안 보여요.
  • AI로 읽을 때만 그 파일이 구글(제미나이)로 보내져요. 이름·주민번호는 가리고 올리면 더 안전해요.
  • 다른 기기로 옮기려면 ⚙️ 설정 → 백업 파일 받기 → 새 기기에서 백업 불러오기.
  • 회사 등 함께 쓰는 컴퓨터라면 다 쓴 뒤 ⚙️ 설정 → 전부 지우기 또는 🔒 잠금을 켜세요.
